# Maurice docs

This folder is an [Obsidian](https://obsidian.md) vault and the long-form documentation of the project. Open the repository root in Obsidian; `.obsidian/` settings stay local.

- `decisions/` — architecture decision records, one file per decision, numbered.
- `notes/` — working notes: research, spikes, session summaries worth keeping.
- The [README](../README.md) at the repository root is the plan and roadmap.
- Tasks live on the [GitHub Project board](https://github.com/users/kmaxxdev/projects/1).
- The GitHub Wiki holds user-facing guides (installation, operations) once there is something to install.

Link notes with `[[wikilinks]]`; keep file names in kebab-case so links survive on GitHub too.
